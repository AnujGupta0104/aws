# Web Designing Practice

This repository contains my Web Designing coursework and practice programs developed while learning frontend web development as a first-year BTech student.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git and GitHub

## Topics Covered

- HTML elements, lists, tables, forms, and webpage structure
- CSS selectors, IDs, classes, and styling
- Navigation bars and webpage layouts
- Flexbox and CSS Grid
- CSS positioning, hover effects, and transitions
- Basic JavaScript programs and functions
- Resume, registration, and login page designs

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open any HTML file in your browser.
4. Ensure any linked CSS and JavaScript files remain in their correct locations.

## Purpose

The purpose of this repository is to practise the concepts taught in class, strengthen my frontend development fundamentals, and track my progress in web development.
